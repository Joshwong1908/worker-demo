FlowAI 文档

AI 工作流平台 —— 多会话聊天 + 可复用提示词工作流，基于 Cloudflare Workers 边缘运行。

① 平台简介

FlowAI 把「聊天」和「工作流」组合成一套可复用的 AI 能力：

  • 💬 聊天：多会话管理、流式输出、随时切换模型，会话自动保存
  • 🔗 工作流：把 System Prompt + User Prompt 固化为模板，填变量即可重复执行
  • ⚡ 边缘运行：全部逻辑跑在 Cloudflare Workers 边缘节点，全球低延迟

② 聊天使用

  • 点击左侧「＋ 新建会话」创建对话，会话列表自动保存最近 50 条
  • 顶部下拉切换模型（见模型说明）
  • Enter 发送，Shift+Enter 换行；回复为流式渲染
  • 会话标题取首条消息前 30 字，hover 会话可删除

③ 工作流指南

工作流 = 可复用的提示词模板。适合固化重复任务：代码评审、翻译、周报、文案生成等。

  1. 进入「🔗 工作流」页 → 「＋ 新建工作流」
  2. 填写名称、System Prompt（角色设定）、User Prompt（任务内容）
  3. Prompt 中用 {{变量名}} 占位，保存后自动识别变量清单
  4. 运行时填入变量值 → 选择模型 → 「▶ 运行」，流式输出结果

④ 变量模板

双花括号语法，运行时自动提取并渲染：

System Prompt: 你是一名{{语言}}翻译专家，只输出译文。
User Prompt:   请翻译以下段落：
{{原文}}

保存后表单会自动出现「语言」「原文」两个输入框。变量留空时保留原占位符不替换。

⑤ API 参考

全部接口均在 https://你的域名 下，无需鉴权（内网/个人使用）：

方法路径说明
GET/api/models可用模型列表
POST/api/chat聊天（SSE 流式）
GET / POST/api/workflows工作流列表 / 创建
GET / PUT / DELETE/api/workflows/:id查 / 改 / 删单个工作流
POST/api/workflows/:id/run运行工作流（SSE）

流式接口示例：

curl -N -X POST https://你的域名/api/chat \
  -H 'content-type: application/json' \
  -d '{"messages":[{"role":"user","content":"你好"}],"model":"@cf/meta/llama-3.2-3b-instruct"}'

SSE 响应：data: {"delta":"文本"} … data: [DONE]

⑥ 模型说明

模型由 Workers AI 提供，默认列表可在 src/llm.js 中调整：

  • Llama 3.2 3B：最快，适合短对话与简单工作流
  • Llama 3.3 70B：大杯，复杂推理与长文写作
  • GPT-OSS 20B：OpenAI 开源模型，均衡之选

全部免费额度内可用，由平台账号统一计费，无需自备 Key。

⑦ 架构与部署

GitHub(main) ──push──▶ Cloudflare Workers Builds ──自动构建部署──▶ 边缘节点
                                                                    ├─ Worker:API(/api/*)+ SSE
                                                                    ├─ Workers AI:LLM 推理
                                                                    └─ 静态资源:本页面(SPA)
  • 存储：优先 D1(SQLite) 持久化，未绑定 D1 时自动降级内存模式(重启丢数据)
  • 本地开发：npx wrangler dev；部署即 git push(推送后约 1 分钟生效)
  • 本页面即文档，无需单独维护文档站

⑧ FAQ

  • Q：会话/工作流存在哪？A：D1 数据库；未配置时存 Worker 内存，重启后丢失(顶部徽标会显示当前模式)。
  • Q：流式输出中断/乱码？A：模型偶发超时，重发即可；工作流可重新运行。
  • Q：如何自定义模型？A：改 src/llm.js 的 MODELS 列表，push 后自动部署。
  • Q：支持图片/文件吗？A：暂不支持，当前为纯文本对话。
